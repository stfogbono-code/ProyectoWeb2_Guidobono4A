PHP

PHP es un lenguaje de programación utilizado principalmente para crear páginas web dinámicas y trabajar con información del lado del servidor.

Historia y características

Fue creado en 1995 por Rasmus Lerdorf. Al principio se utilizaba para tareas sencillas en páginas personales, pero con el tiempo se convirtió en un lenguaje completo para desarrollo web.

¿Para qué se usa?

Se utiliza para trabajar con formularios, bases de datos, usuarios, sesiones, sitios web dinámicos y sistemas de administración.

Ejemplo sencillo

echo 'Hola mundo';

Dato interesante

Muchos sitios web famosos utilizaron PHP durante años, y sigue siendo muy usado en sistemas de gestión de contenidos como WordPress.
