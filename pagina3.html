Java

Java es un lenguaje de programación muy conocido que permite crear programas capaces de funcionar en diferentes sistemas operativos.

Historia y características

Fue creado en 1995 por la empresa Sun Microsystems. Su objetivo era permitir que un mismo programa pudiera ejecutarse en Windows, Linux, macOS y otros sistemas sin tener que reescribir gran parte del código.

¿Para qué se usa?

Se usa en aplicaciones empresariales, programas de escritorio, servidores, sistemas bancarios, herramientas educativas y muchos proyectos de gran tamaño.

Ejemplo sencillo

System.out.println("Hola mundo");

Dato interesante

Java utiliza una máquina virtual llamada JVM, que ayuda a que el mismo programa pueda funcionar en distintos sistemas operativos.
