JavaScript

JavaScript es uno de los lenguajes más importantes de Internet. Se usa principalmente para agregar interacción y comportamiento a las páginas web.

Historia y características

Fue creado en 1995 por Brendan Eich. Originalmente se diseñó para funcionar dentro de los navegadores web. Con el tiempo creció muchísimo y hoy también puede utilizarse en servidores y aplicaciones.

¿Para qué se usa?

Sirve para crear menús interactivos, formularios, juegos, animaciones, aplicaciones web y también servidores usando herramientas como Node.js.

Ejemplo sencillo

let nombre = 'Stefano';\nconsole.log('Hola ' + nombre);

Dato interesante

Aunque su nombre se parece a Java, JavaScript y Java son lenguajes diferentes y fueron creados con objetivos distintos.
